# 🎰 seeKazino

Виртуальное казино с играми, профилем и системой уровней.

## 🚀 Как задеплоить на Cloudflare Pages

1. Создай репозиторий на GitHub и закинь туда все файлы из этой папки
2. Зайди на [dash.cloudflare.com](https://dash.cloudflare.com)
3. **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
4. Выбери свой репозиторий
5. Настройки сборки:
   - **Build command:** оставь ПУСТЫМ
   - **Output directory:** `.` (точка)
6. Нажми **Deploy**

## ⚠️ Важно

Пока сайт работает на **localStorage** (данные в браузере).
Для полноценной работы с аккаунтами нужно подключить **Cloudflare D1** (базу данных).
Инструкцию дам отдельно!
